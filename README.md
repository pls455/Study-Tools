# Study Tools | أدوات الطالب
منصة أدوات تعليمية Client-Side جاهزة لـ GitHub Pages.
- HTML + CSS + Vanilla JavaScript
- لا Database ولا Backend ولا Login
- LocalStorage للمفضلة والملاحظات والمهام والإعدادات
- Responsive + Dark Mode + IntersectionObserver + reduced motion
- أسعار العملات غير وهمية، والواجهة جاهزة للربط مع API مستقبلًا.
